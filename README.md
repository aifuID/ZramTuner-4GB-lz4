**KernelSU / APatch / Magisk module** — sets ZRAM to **4GB + lz4**, applied instantly and persistent on every boot.

## ✨ Features
- ZRAM **4GB** + **lz4** (fast compression = smooth multitasking)
- Auto backup of original zRAM settings at first boot
- Uninstall = auto restore original settings
- Anti-bootloop: auto-abort if kernel has no lz4 profile

##  Requirements
- Root with module support (KernelSU / APatch / Magisk)
- Kernel with `lz4` zram support

## 🚀 Install
1. Download `Zram_4GB+lz4.zip` from **Releases**
2. Flash it in your root manager
3. Reboot
4. Verify:
```
cat /sys/block/zram0/disksize        # 4294967296
cat /sys/block/zram0/comp_algorithm  # lzo lzo-rle [lz4] zstd
grep zram0 /proc/swaps               # zram0 active
```
